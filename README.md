# Moonwatch

Live 3D Moon tracker at **https://mymoon.live**: today's moon phase, illumination, moonrise and moonset, visibility and upcoming phases for 50 cities on every continent, in English and Thai.

Everything is calculated in the browser with [Astronomy Engine](https://github.com/cosinekitty/astronomy) (MIT) and drawn with [three.js](https://threejs.org) (MIT). Moon and Earth textures come from the three.js examples.

Hosted on GitHub Pages. `index.html` is the whole site.
